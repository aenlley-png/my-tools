紫鸟插件拉取频率

插件在每次 /plugin/stock/inventory/download 时按这里的间隔重置 alarm。 默认 1440 分钟 = 1 天 1 次。改完保存即生效，下一次插件 download 自动跟上。

提示：1440 = 1 天，60 = 1 小时，5 = 5 分钟（紧急排查时用）

业务系统数据接入（"系统值"来源）

让你们的业务系统按以下格式 POST 到 Worker，即可参与跨源比对：

POST [Worker URL]/api/snapshots
Authorization: Bearer <system 设置里的 api_token，可空>
Content-Type: application/json

{
  "items": [
    {"source_code":"system","scope_key":"B0XXXXXX","metric":"fba_available","value":120},
    {"source_code":"system","scope_key":"B0XXXXXX","metric":"fba_reserved","value":3}
  ]
}

一次最多 200 条；scope_key 用 ASIN 或 SKU；metric 用 fba_available / fba_reserved / fba_inbound / fba_unfulfillable。 默认规则已经按 source=system 配好，业务系统推数据后自动生效。
